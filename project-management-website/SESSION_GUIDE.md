## Important Context for AI Assistants

### Project Overview:
- **Objective**: Build Bangladesh's most advanced AI tax engine
- **Approach**: Technical-first with multi-hop RAG for precise tax calculations
- **Timeline**: 5-year plan from bootstrap to ₹100+ crore revenue
- **Unique Value**: Multi-hop reasoning across tax acts, NBR circulars, and precedents

### Technical Stack:
- **AI**: GPT-4o + text-embedding-3-large for multi-hop RAG
- **Backend**: FastAPI with PostgreSQL and Redis
- **Frontend**: Next.js with TypeScript
- **Integration**: WhatsApp Business API, NBR systems
- **Vector Store**: ChromaDB + Pinecone hybrid

### Key Features:
- **Multi-hop RAG**: Cross-reference validation between acts, circulars, and precedents
- **Context Management**: Conversation history and user profiling
- **Tax Optimization**: AI-powered suggestions and scenario analysis
- **Government Integration**: NBR API integration and e-return automation
